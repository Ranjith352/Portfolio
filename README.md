## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or v20+)
- npm

### Installation & Run
```bash
# Clone the repository
git clone https://github.com/Ranjith352/portfolio.git

# Navigate to folder
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
```
